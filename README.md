# Sharan Krishna Vaka — Portfolio

A responsive personal portfolio built with Next.js, React, Tailwind CSS, and Lucide React.

## Run locally

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

## GitHub Pages deployment

Every push to `main` builds and deploys the static site using GitHub Actions. The production site will be available at:

https://sharankrishna05.github.io/Sharan-Krishna/

In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The workflow is also available to run manually from the Actions tab.
